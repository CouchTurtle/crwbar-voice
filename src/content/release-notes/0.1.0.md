## First crwbar voice release

This starts a separate `0.1.x` release line for the personal fork.

### Files and voice notes

Drop an audio file onto the recording bar to transcribe it locally. Common
audio formats are supported:

- WAV
- MP3
- M4A (AAC)
- FLAC
- OGG / OGA (Vorbis or Opus)
- OPUS, including WhatsApp voice notes

Imported audio is converted to 16 kHz mono internally before transcription.

### Clipboard workflow

An optional setting copies each completed transcription directly to the
clipboard. Push-to-talk and toggle-to-talk remain available.

### History

The history now distinguishes microphone recordings from imported files.
Filters only appear when matching entries exist, keeping empty states quiet.

### New identity and overlay

The app uses its own bundle identifier, icon, wordmark, tray states, and a
refined recording/transcription overlay.

The macOS build has been tested. Windows and Linux builds are not verified yet.
