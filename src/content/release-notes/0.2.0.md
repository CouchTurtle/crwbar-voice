## Voice actions, appearance, and a launch fix

### AI & Voice Actions

A new tab replaces the old post-processing section. Speak an instruction and
have it turned into text using your own context and a backend of your choice:

- a configured API provider
- the Codex CLI
- the Claude CLI

Persistent context and an optional clipboard context can be attached to every
request. Voice actions have their own shortcut, separate from plain
transcription.

Speech recognition still runs entirely on your machine. Voice actions are the
exception: when you use them, the request goes to the backend you selected.

### Appearance

Colour settings moved from *About* into *General → Appearance*:

- **Accent colour** — pick any colour for buttons, highlights and the recording
  bar. Reset returns to the default orange.
- **Emil Mode** — the accent colour cycles through the rainbow. Clicking the
  name three times switches to double speed.

### Audio ducking

Other audio is now faded down while recording instead of being muted outright,
and faded back up afterwards. The setting lives in *General → Sound* and is off
by default.

How quickly that happens is adjustable — **Instant**, **Fast**, **Normal** or
**Smooth**. Fading back up is always a little slower than fading down, so the
music returns without being abrupt.

### File transcription

Dropping an audio file onto the recording bar is now an explicit setting and is
off by default. While a file is dragged over the bar, the bar highlights and
shows where to drop it.

### Fixes

- **The app could fail to start from Finder.** macOS passes an extra argument
  when launching a bundled app, which the app rejected and quit over. It now
  ignores arguments it does not recognise instead of refusing to start.
- **The global shortcut stayed dead when the app started hidden.** Shortcuts
  were only registered once the main window had been drawn, so starting to the
  menu bar left the hotkey inactive. They are now registered at startup.
- The interface defaults to English regardless of system language, and can be
  changed in *About → Language*.

The macOS build has been tested. Windows and Linux builds are not verified yet.
