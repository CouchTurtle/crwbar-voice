## Audio file imports that actually import

A bugfix release. Importing an audio file worked for some recordings and failed
for others, which turned out to be two separate problems.

### Voice memos from an iPhone

Recorders such as iPhone Voice Memos store the file's index *after* the audio.
Reading one requires jumping to the end of the file, which the decoder was not
set up to do — so those recordings were rejected as an unknown format even
though nothing was wrong with them. A 19-minute recording that failed this way
now transcribes end to end.

### Apple Lossless

Voice memos recorded with the Lossless setting use ALAC, which was not among the
bundled decoders. They now import like any other file.

### Picking a file

*General* has a **Choose audio file…** button, so importing no longer depends on
hitting the recording bar with a drag. Files can also be dropped onto the main
window.

### Diagnostics

Failed imports are written to the log as well as shown in the app. Previously
the message vanished with the notification, leaving nothing to look at
afterwards.

Supported imports: WAV, MP3, M4A (AAC and ALAC), FLAC, OGG/OGA and OPUS,
including WhatsApp voice notes.
