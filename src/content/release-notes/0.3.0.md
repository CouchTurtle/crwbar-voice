## Reaching back at a transcript, and a home for recorded audio

### Two shortcuts for the last transcript

The clipboard used to be an all-or-nothing switch: either every transcription
overwrote it, or none did and the only way back to one was the tray menu.

- **Option+C** copies the last transcription to the clipboard.
- **Option+V** inserts it into whatever field has focus and puts the clipboard
  back the way it was.

Both live in _General_ and can be reassigned — or switched off entirely with the
✕ next to them. That matters more than it sounds: a global shortcut swallows its
combination everywhere, and Option+C and Option+V are how macOS types ç and √.

### A tab for transcribing files

_Transcribe_ is now its own section instead of a card wedged into _General_.

Picking a file there transcribes it **in the app**. Nothing is typed into other
windows, nothing appears on the recording bar, and the transcript is shown where
you can read and copy it — which is what an hour of meeting audio actually needs.
It still lands in _History_, tagged as a file transcription.

Dropping a file on the recording bar is unchanged: it still behaves like
dictation and inserts the text where you are typing.

Files can be dropped straight onto that tab, and it shows how far along a long
recording is — with an estimate of the time left. The estimate is measured on
your machine as the transcription runs rather than read off a spec sheet, so it
reflects the model you picked and the Mac you are on.

### A separate model for files

Dictation needs a model that keeps up live. A recorded meeting does not, so
_Transcribe_ has its own model setting and can use a slower, more accurate one.
Left alone, it follows the dictation model as before.

The model is chosen from a list showing accuracy and speed, the same way the
_Models_ tab presents them, and a running transcription can be cancelled.

### Dictating no longer kills a running file transcription

Speaking while a long file was being transcribed could end that transcription
outright, throwing away everything it had already done. Live dictation borrows
the transcription engine, and the file run treated the loan as a failure. It now
waits for the engine to come back and carries on.

### Also

- Any shortcut can now be cleared, not just the new ones.
- Long recordings show elapsed time while they run, so a quiet five minutes no
  longer looks like a hang.

Supported imports: WAV, MP3, M4A (AAC and ALAC), FLAC, OGG/OGA and OPUS,
including WhatsApp voice notes and Apple Voice Memos.
